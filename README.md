# Simply Furniture 🛋️

An interactive 3D furniture scrolling animation website featuring a minimalist, modern UI. 

## 🚀 Tech Stack
- **Framework:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **3D Engine:** React Three Fiber / Three.js

## 🛠️ Run it Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/offxankit/simply-furniture.git](https://github.com/offxankit/simply-furniture.git)

   Click that green **Add a README** button on your GitHub page, paste this clean template inside, and hit **Commit changes** at the top right.
